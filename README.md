# Applied Bioinformatics Project
This repository contains a project for the Applied Bioinformatics course at Chalmers University of Technology.

The project was conducted to learn and apply bioinformatics workflows, including Bash scripting, job submission to high-performance computing clusters, containers, DESeq2, data processing, quality control, and data visualization.

The goal of the project was to study host-bacteria interactions in the stomach, specifically in patients with gastric carcinoma. The analysis focuses on how gene expression in the bacterium *Helicobacter pylori* may affect disease progression.

The data analysis is based on dual RNA-seq data, including both bacterial and host transcriptomes, from patients in the following groups:

- Control
- Chronic gastritis
- Atrophic gastritis
- Intestinal metaplasia
- Gastric carcinoma
